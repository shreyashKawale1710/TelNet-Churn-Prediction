# 📊 TelNet Customer Churn Prediction

## 🚀 Project Overview

In this project, I analyzed telecom customer data and built a machine learning model to predict churn with over 90% accuracy.
This project uses Machine Learning to predict whether a customer will churn, enabling businesses to take proactive retention actions.

---

## 🎯 Objective

* Predict customer churn using historical data
* Identify high-risk customers
* Provide actionable insights to reduce churn

---
## 🧩 My Contribution
- Performed data cleaning and preprocessing
- Built and evaluated Logistic Regression model
- Analyzed model performance using multiple metrics
- Interpreted results to derive business insights

---
## 🧠 Model Used

* Logistic Regression

---

## 📈 Model Performance

| Metric    | Score  |
| --------- | ------ |
| Accuracy  | 90.50% |
| Precision | 88.35% |
| Recall    | 92.86% |
| F1-Score  | 90.55% |
| ROC-AUC   | 97.47% |

---

## 📊 Confusion Matrix

| ---------- | ------------ | ------------- |
| Actual No  | 90           | 12            |

## 🔍 Key Insights

* The model achieves **high recall (92.86%)**, meaning it successfully identifies most customers who are likely to churn
* Strong ROC-AUC score (**97.47%**) indicates excellent model performance
* Balanced precision and recall ensure reliable predictions for business use
